"Elementals" commonly known around the internet as "HTML ELEMENTS" or "HTML TAGS" are the basic building blocks of our design system. To see how everything is set up, you can view this source code directly or check out our documentation (link provided separately). Below, you'll find examples of how to use this design system to create elements. Our approach relies primarily on standard HTML elements, with minimal use of custom classes. The only div classes we aim to use are 'card' and 'panel', which provide structure and styling to our components.
