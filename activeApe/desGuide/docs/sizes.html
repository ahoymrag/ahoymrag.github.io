Sizing Guide

This guide explores the various sizing classes provided by the @elementals.css stylesheet, which help in creating responsive and structured layouts.

Full Size

This section is styled with the .size-full class, which stretches the section to use the full width of its container.

Half Size

This section uses the .size-half class, making it occupy half of the width of its container.

Quarter Size

The .size-quarter class is applied here, allowing this section to take up a quarter of the width of its container.
