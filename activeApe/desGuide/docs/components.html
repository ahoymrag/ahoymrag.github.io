Components

This section covers the different components available in My Design System.

Components are reusable UI elements that can be used to build complex user interfaces. They are built using the basic building blocks, or elementals, of the design system.

Elementals

Elementals are the smallest units of a design system. They are the basic building blocks used to create more complex components.

Here is an example of an elemental component from elementals.html:

<div class="panel">
    <div class="card">
        <header>Create Cluster</header>
        <main>
            <p>You'll need a bot cluster before you can deploy your robot army. Create a cluster with the button below</p>
        </main>
        <footer>
            <button>Create Cluster</button>
        </footer>
    </div>
</div>

This example shows a simple card component with a header, main content, and a footer. The card is wrapped in a panel for additional styling.

Using Elementals

To use elementals in your own components, you can follow the structure and styling provided in elementals.html. Here is how you can create a similar component:

<div class="panel">
    <div class="card">
        <header>Component Header</header>
        <main>
            <p>This is the main content of the component.</p>
        </main>
        <footer>
            <button>Action</button>
        </footer>
    </div>
</div>

By following this structure, you can create consistent and reusable components for your design system.

HTML Elements and Styling

HTML elements are the building blocks of web pages. They include structural elements like <div>, <header>, and <footer>, as well as inline elements like <span> and <a>. Over time, HTML has evolved to include semantic elements like <article>, <section>, and <nav>, which provide more meaningful structure to web content.

Styling these elements has also evolved significantly. Initially, styling was done using inline styles and the <font> tag. With the advent of CSS, styling became more powerful and flexible, allowing for separation of content and presentation. Modern CSS includes features like Flexbox and Grid for layout, as well as advanced selectors and pseudo-classes for more precise styling.

For more detailed information, you can refer to resources like W3Schools and MDN Web Docs.

Shortcuts for Common HTML Elements

  • <div>: A generic container for flow content.
  • <span>: A generic container for inline content.
  • <header>: Represents introductory content.
  • <footer>: Represents footer content.
  • <nav>: Represents a section with navigation links.
  • <section>: Represents a standalone section.
  • <article>: Represents a self-contained composition.
  • <a>: Defines a hyperlink.
  • <button>: Represents a clickable button.
  • <ul>: Defines an unordered list.
  • <li>: Defines a list item.
  • <h1> - <h6>: Define HTML headings.
  • <p>: Defines a paragraph.
  • <img>: Embeds an image.
  • <form>: Represents a document section containing interactive controls.
  • <input>: Defines an input control.

Explanation of the "Create Cluster" Card

The "Create Cluster" card is a reusable component built using the basic building blocks, or elementals, of the design system. It is defined in the elementals.html file and styled using the elementals.css file.

Here is how the elementals.html and elementals.css files work together to create the "Create Cluster" card:

HTML Structure

The elementals.html file provides the structure of the card using HTML elements like <div>, <header>, <main>, and <footer>. The card is wrapped in a <div class="panel"> for additional styling.

<div class="panel">
    <div class="card">
        <header>
            <h2>Create Cluster</h2>
        </header>
        <main>
            <p>You'll need a bot cluster before you can deploy your robot army. Create a cluster with the button below</p>
        </main>
        <footer>
            <button>Create Cluster</button>
        </footer>
    </div>
</div>

CSS Styling

The elementals.css file provides the styles for the .panel and .card classes. The .panel class adds a background, border-radius, box-shadow, and padding to the panel. The .card class adds similar styles to the card, with additional hover effects for interactivity. The button class styles the button inside the card, making it visually appealing and interactive.

/* Panel styling */
.panel {
    background: rgba(255, 255, 255, 0.1);
    border-radius: 10px;
    box-shadow: 0 4px 6px rgba(0, 0, 0, 0.1);
    backdrop-filter: blur(10px);
    -webkit-backdrop-filter: blur(10px);
    padding: 20px;
    border: 1px solid rgba(255, 255, 255, 0.2);
    transition: all 0.3s ease;
}

.panel:hover {
    background: rgba(255, 255, 255, 0.15);
    box-shadow: 0 8px 12px rgba(0, 0, 0, 0.15);
}

/* Card styling */
.card {
    max-width: 100%;
    margin: 5px;
    background: rgba(255, 255, 255, 0.1);
    border-radius: 10px;
    box-shadow: 0 4px 6px rgba(0, 0, 0, 0.1);
    backdrop-filter: blur(10px);
    -webkit-backdrop-filter: blur(10px);
    padding: 20px;
    transition: transform 0.3s ease, background 0.3s ease;
}

.card:hover {
    box-shadow: 0 8px 12px rgba(0, 0, 0, 0.2);
    background: rgba(255, 255, 255, 0.2);
}

/* Button styling */
button {
    position: relative;
    z-index: 1;
    overflow: hidden;
    text-transform: uppercase;
    font-weight: 300;
    font-family: 'Roboto', sans-serif;
    font-size: 0.9rem;
    letter-spacing: 0.05em;
    line-height: 1.2;
    background: rgba(255, 255, 255, 0.1);
    color: black;
    border: 1px solid black;
    border-radius: 8px;
    display: flex;
    padding: 12px 24px;
    justify-content: center;
    align-items: center;
    gap: 8px;
    align-self: stretch;
    text-align: center;
    width: 100%;
    backdrop-filter: blur(10px);
    -webkit-backdrop-filter: blur(10px);
    transition: all 0.3s ease;
}

button:hover {
    cursor: pointer;
    background: rgba(255, 255, 255, 0.2);
    border: 1px solid rgba(255, 255, 255, 0.3);
    box-shadow: 0 4px 15px rgba(0, 0, 0, 0.1);
    transform: translateY(-2px);
}

By combining the structure defined in elementals.html with the styles provided in elementals.css, the "Create Cluster" card is created with a consistent and reusable design.
