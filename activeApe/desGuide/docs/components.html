Components

This section covers the different components available in My Design System.

Components are reusable UI elements that can be used to build complex user interfaces. They are built using the basic building blocks, or elementals, of the design system.

Elementals

Elementals are the smallest units of a design system. They are the basic building blocks used to create more complex components.

Here is an example of an elemental component from elementals.html:

<div class="panel">
    <div class="card">
        <header>Create Cluster</header>
        <main>
            <p>You'll need a bot cluster before you can deploy your robot army. Create a cluster with the button below</p>
        </main>
        <footer>
            <button>Create Cluster</button>
        </footer>
    </div>
</div>

This example shows a simple card component with a header, main content, and a footer. The card is wrapped in a panel for additional styling.

Using Elementals

To use elementals in your own components, you can follow the structure and styling provided in elementals.html. Here is how you can create a similar component:

<div class="panel">
    <div class="card">
        <header>Component Header</header>
        <main>
            <p>This is the main content of the component.</p>
        </main>
        <footer>
            <button>Action</button>
        </footer>
    </div>
</div>

By following this structure, you can create consistent and reusable components for your design system.
