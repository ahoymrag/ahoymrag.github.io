Final Colors

This is the final colors page, detailing the use cases for each defined color in the design.

Color Use Color Name Description Hex Code HTML Elements
Base Color Base Primary branding color used as the base for generating other color variations. It appears in various elements like buttons, links, and highlights to maintain brand consistency. #ff0060 Used in various elements for primary color
Primary Color Primary Directly uses the base color. Employed in primary interface elements such as buttons, links, and highlights, ensuring that these elements are visually prominent. var(--color-base) Buttons, links, highlights
Secondary Color Secondary This color is a lighter shade of the base color, used for secondary interface elements like secondary buttons and background sections. It helps in differentiating between primary and secondary actions while maintaining visual harmony. hsl(from var(--color-base) h s 80%) Secondary buttons, background sections
Accent Color Accent An accent color derived from the base, used for drawing attention to elements like alerts, warnings, and active states. It's typically brighter or more saturated to stand out against other elements. hsl(from var(--color-base) h s 60%) Alerts, warnings, active states
Background Color Background A very light shade of the base color, used primarily for background areas. It provides a subtle contrast against primary content, making the interface easier on the eyes and more readable. hsl(from var(--color-base) h s 90%) Used for background areas to offset against primary content
Success Color Success Used to indicate successful operations, typically in notifications or status icons. #39ffc0b9 Notifications, Status Icons
Error Color Error Used to highlight errors or critical issues, often in alerts or form validations. #ff4470 Alerts, Form Validations
Info Color Info Used for informational messages and tooltips, providing additional context to users. #007B83 Tooltips, Info Messages
