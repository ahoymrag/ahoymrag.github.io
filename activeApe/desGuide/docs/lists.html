Lists

This section covers the list components available in My Design System.

Lists are used to display a series of related content items in a structured manner. They can be styled and customized to fit various design needs.

Example of a List Component

Here is an example of a list component from elementals.html:


            <ul>
                <li>Item 1</li>
                <li>Item 2</li>
                <li>Item 3</li>
            </ul>

This example shows a simple list component with three items. The list is wrapped in a card and panel for additional styling.

Lists CSS

                        
                          
                            ul {
                                list-style-type: none; /* Removes the default list-style */
                                padding: 0; /* Removes padding */
                                margin: 0; /* Removes margin */
                                font-family: var(--font-family); /* Uses the custom font family defined in :root */
                                color: #333; /* Sets the text color */
                            }
                            
                            li {
                                text-decoration: none; /* Ensures no text decoration */
                                list-style-type: none; /* Removes list style */
                                padding-left: 0; /* Removes left padding */
                                padding: 0; /* Removes all padding */
                                margin: 0; /* Removes all margins */
                            }
