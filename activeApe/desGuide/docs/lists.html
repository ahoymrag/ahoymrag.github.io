Lists

This section covers the list components available in My Design System.

Lists are used to display a series of related content items in a structured manner. They can be styled and customized to fit various design needs.

Example of a List Component

Here is an example of a list component from elementals.html:

<div class="panel">
    <div class="card">
        <main>
            <ul>
                <li>Item 1</li>
                <li>Item 2</li>
                <li>Item 3</li>
            </ul>
        </main>
    </div>
</div>

This example shows a simple list component with three items. The list is wrapped in a card and panel for additional styling.

Using Lists

To use lists in your own components, you can follow the structure and styling provided in elementals.html. Here is how you can create a similar list component:

<div class="panel">
    <div class="card">
        <main>
            <ul>
                <li>List Item 1</li>
                <li>List Item 2</li>
                <li>List Item 3</li>
            </ul>
        </main>
    </div>
</div>

By following this structure, you can create consistent and reusable list components for your design system.

HTML Elements and Styling

HTML elements like <ul> and <li> are used to create lists. These elements can be styled using CSS to match the design requirements of your system.

For more detailed information, you can refer to resources like W3Schools and MDN Web Docs.

Explanation of the List Component

The list component is a reusable element built using the basic building blocks, or elementals, of the design system. It is defined in the elementals.html file and styled using the elementals.css file.

Here is how the elementals.html and elementals.css files work together to create the list component:

HTML Structure

The elementals.html file provides the structure of the list using HTML elements like <ul> and <li>. The list is wrapped in a <div class="panel"> and <div class="card"> for additional styling.

<div class="panel">
    <div class="card">
        <main>
            <ul>
                <li>Item 1</li>
                <li>Item 2</li>
                <li>Item 3</li>
            </ul>
        </main>
    </div>
</div>

CSS Styling

The elementals.css file provides the styles for the .panel and .card classes. The .panel class adds a background, border-radius, box-shadow, and padding to the panel. The .card class adds similar styles to the card, with additional hover effects for interactivity. The ul and li elements can be styled to match the design requirements.

/* Panel styling */
.panel {
    background: rgba(255, 255, 255, 0.1);
    border-radius: 10px;
    box-shadow: 0 4px 6px rgba(0, 0, 0, 0.1);
    backdrop-filter: blur(10px);
    -webkit-backdrop-filter: blur(10px);
    padding: 20px;
    border: 1px solid rgba(255, 255, 255, 0.2);
    transition: all 0.3s ease;
}

.panel:hover {
    background: rgba(255, 255, 255, 0.15);
    box-shadow: 0 8px 12px rgba(0, 0, 0, 0.15);
}

/* Card styling */
.card {
    max-width: 100%;
    margin: 5px;
    background: rgba(255, 255, 255, 0.1);
    border-radius: 10px;
    box-shadow: 0 4px 6px rgba(0, 0, 0, 0.1);
    backdrop-filter: blur(10px);
    -webkit-backdrop-filter: blur(10px);
    padding: 20px;
    transition: transform 0.3s ease, background 0.3s ease;
}

.card:hover {
    box-shadow: 0 8px 12px rgba(0, 0, 0, 0.2);
    background: rgba(255, 255, 255, 0.2);
}

/* List styling */
ul {
    list-style-type: disc;
    padding-left: 20px;
}

li {
    margin-bottom: 10px;
}

By combining the structure defined in elementals.html with the styles provided in elementals.css, the list component is created with a consistent and reusable design.
