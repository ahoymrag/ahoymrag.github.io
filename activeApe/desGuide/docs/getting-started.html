Understanding Elementals

"Elementals" refer to the basic HTML elements or tags that serve as the foundational building blocks of the ApeWorX Design System. These include standard HTML elements with minimal reliance on custom classes to enhance accessibility, maintainability, and compatibility with various frameworks.


The design system utilizes a few custom classes like 'card' and 'panel' to provide additional structure and styling to components. These classes help in organizing content in a visually appealing and structured manner.

The design system advocates for the use of semantic HTML elements over generic <div> tags. This not only improves SEO and accessibility but also aligns well with HTML5 semantic guidelines.


Examples and demos are provided to demonstrate the practical use of these elementals in creating complex layouts and components. These examples serve as a practical guide for users to implement the design system in their projects.
