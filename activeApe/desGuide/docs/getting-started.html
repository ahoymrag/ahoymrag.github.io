Getting Started

This is the getting started guide for ApeWorx IO

In this section, we will cover the basic HTML elements that are used in this design system. This includes headings, paragraphs, lists, links, and other common HTML elements.

We emphasize using semantic HTML elements over generic <div> classes. This approach improves accessibility, SEO, and maintainability of the code. Semantic elements like <header>, <nav>, <main>, and <footer> provide meaningful structure to the document.

Additionally, this design system is built with Python development and agile methodologies in mind. Using semantic HTML elements aligns well with frameworks like HTMX, which allows for dynamic content updates without relying heavily on JavaScript. This results in cleaner, more maintainable code that is easier to debug and extend.

Below are some examples of these elements:

  • Headings: Use <h1> to <h6> tags for different levels of headings.
  • Paragraphs: Use the <p> tag for paragraphs.
  • Lists: Use <ul> for unordered lists and <ol> for ordered lists.
  • Links: Use the <a> tag to create hyperlinks.
