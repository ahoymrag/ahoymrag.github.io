Zuki - Your Personal Robot

What is Zuki?

Zuki is a Raspberry Pi-powered personal robotic system that can be controlled via a command-line interface (CLI). It can also provide interactive features like facial expressions, speech, and more. It's modular, so you can replace placeholder functions (e.g., motor control, AI) with your own hardware or software solutions, making it very customizable!

Key Features

  • Command-line interface (CLI) for direct control
  • Optional facial expressions and speech bubble UI
  • Speech recognition and text-to-speech (TTS) modules
  • Motor control and sensors (if available)
  • AI-based question/answer and potential expansions

Getting Started at Home

  1. Clone the Repository:
    git clone https://github.com/ahoymrag/engine.zuki.git
  2. Set Up a Virtual Environment:
    python -m venv .zuki
    source .zuki/bin/activate     (Mac/Linux)
  3. Install Dependencies:
    pip install -r requirements.txt
  4. Option 1: Run Zuki in CLI Mode
    python main.py
  5. Option 2: Run Zuki with a Graphical UI
    python zuki_ui.py
    This will show Zuki's visual expressions and speech bubbles.
  6. Option 3: Run Both CLI & UI Simultaneously
    See zuki.sh (Mac/Linux) or zuki.bat (Windows).

How It Works

Zuki uses Python scripts for each part of its functionality:

  • main.py: CLI entry point for controlling everything.
  • zuki_ui.py: A Pygame-based interface that displays Zuki's "face" and speech bubbles.
  • web_server.py: A Flask server that provides remote control and commands over HTTP.
  • speech.py: Text-to-speech (TTS) and (optional) speech recognition logic.
  • piano.py: A playful feature for generating musical notes through your computer's audio or a speaker connected to Zuki.

Each file can be customized or replaced. For example, you can enhance motor_control.py if you have motors or sensors.py if you have distance sensors. The idea is that all the building blocks are ready for you to tweak or extend based on your hardware and personal creativity!
