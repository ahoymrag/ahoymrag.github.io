Zuki

Your Friendly, Fantasy-Inspired Personal Robot Companion

What is Zuki?

Zuki is a plushy, lovable personal robot powered by Raspberry Pi. With a friendly CLI, optional face UI, and full modularity, Zuki can become whatever you imagine — from music maker to life assistant.

Key Features

  • Command-line interface (CLI) for direct control
  • Adorable facial expressions with speech bubbles
  • Speech recognition and text-to-speech modules
  • Optional motor control and sensor expansions
  • Playful mini-apps like a piano or emotion simulator

How It Works

Zuki runs on Python with separate scripts for modularity:

  • main.py — CLI control
  • zuki_ui.py — Facial expression UI
  • speech.py — TTS + speech recognition
  • piano.py — Play music via commands
  • web_server.py — Remote control via Flask

Get Started


git clone https://github.com/ahoymrag/engine.zuki.git
cd engine.zuki
python -m venv .zuki
source .zuki/bin/activate  # Mac/Linux
pip install -r requirements.txt
python main.py
