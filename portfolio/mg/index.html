Overview

Mountain Gorilla Command Center (MGCC) is a modern, web-based dashboard for managing, training, and monitoring your AI bots in real time. Designed for intuitive control and deep analytics, MGCC empowers you to deploy, train, and collaborate with specialized bots for finance, productivity, and more — all from a beautiful browser interface.

For power users and fans of retro tech, MGCC also features a classic ASCII/CLI mode inspired by collectible games and terminal nostalgia.

Features

  • Live Web Dashboard: Manage, train, and monitor your bots in real time from any browser
  • Real-Time Analytics: Visualize bot activity, system status, and performance instantly
  • Bot Collaboration: Deploy, upgrade, and coordinate multiple specialized bots
  • Finance & Automation: Track wallets, automate strategies, and respond to blockchain events
  • Classic CLI Mode: Optional ASCII/terminal interface for advanced users and retro fans
  • Modular Design: Easily extend and create custom bots for your needs

Tech Stack

Python 3.10+ Rich CLI Framework ApeWorX & Silverback SDK Vyper-inspired Simplicity ASCII Art & Animation

Installation & Setup

git clone https://github.com/yourusername/mountain-gorilla.git
cd mountain-gorilla

# Create a virtual environment (recommended)
python3 -m venv venv
source venv/bin/activate  # Linux/Mac
.\venv\Scripts\activate   # Windows

# Install dependencies
pip install -r requirements.txt

# Run MGCC
python main.py
