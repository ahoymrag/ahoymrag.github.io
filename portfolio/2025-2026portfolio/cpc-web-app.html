CPC - WEB - APP

A Flask web application for Christ Presbyterian Church New Haven, built around dynamic church content, administration, and searchable archives.

What it is

The repository describes a content-driven church site with admin workflows for announcements, sermons, events, podcasts, and gallery images. Its public-facing pages include the home, sermons, podcasts, and about routes.

Portfolio description based on the project README and repository structure.

Documented capabilities

  • Flask-Admin content management for announcements, sermons, events, podcasts, and gallery images
  • Searchable and filterable sermon archives with advanced search
  • Podcast series and episode management with API endpoints
  • Responsive, mobile-first frontend with Alpine.js and vanilla JavaScript
  • REST-style content APIs for announcements, sermons, podcasts, gallery, and events

Stack

Python · Flask · SQLAlchemy · Flask-Migrate · Flask-Admin · HTML5 · CSS3 · Alpine.js · Vanilla JavaScript · SQLite (development) · PostgreSQL (production)
