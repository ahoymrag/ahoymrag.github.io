Pathr

Like Strava for driving: record trips, discover scenic routes, and build a personal map of everywhere you’ve been.

Repository-backed feature set

  • Trip recording with start, stop, pause, resume, and background tracking
  • Live route visualization and trip details
  • Trip library with filtering and search
  • Shareable links, privacy controls, and a heuristic scenic score

Stack

TypeScript · React · Vite · React Router · Leaflet · TanStack Query · Tailwind CSS · Supabase (planned backend)

MVP / work in progress

The repository contains web routes and recording components; several README items are described as next-stage or planned features.
