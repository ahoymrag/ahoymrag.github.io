What it is

Ahoy Indie Media is direct-to-artist media and commerce infrastructure: a home for discovering independent music, podcasts, events, film, artists, and studio work, with tools to save, collect, and take media with you.

Technical architecture

Python · Flask · Vue 3 · TypeScript · Vite · Pinia · Tailwind CSS · SQLAlchemy · PostgreSQL · SQLite · Alembic · Redis · Three.js

Modular backend and Vue SPA distributed across Web/PWA, Capacitor mobile, and Electron desktop targets.
